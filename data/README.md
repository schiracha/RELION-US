# `data/` — extracted RELION job definitions

`job_definitions_raw.json` is generated by `extract_job_definitions.py` from a
RELION source checkout. For each of the 32 job types it holds:

- `options` — every field's key, type, default value and **help string**,
- `commands_source` — the **verbatim C++ body** of that job's
  `getCommands<Job>Job()` function,
- `program_guess`, `flags_used`, `tab_layout` — derived metadata.

The help strings and `commands_source` are copied unmodified from RELION:

    Copyright (C) MRC Laboratory of Molecular Biology
    RELION — https://github.com/3dem/relion
    GNU General Public License, version 2 or later

Redistributing this file therefore carries RELION's GPL-2.0-or-later terms, and
RELION's file headers require the copyright notice to travel with it. If you
copy `job_definitions_raw.json` out of this repository, copy this notice too.
See `NOTICE.md` at the repository root.

Regenerate it against a different RELION version with:

```bash
git clone --depth 1 https://github.com/3dem/relion.git /tmp/relion_src
python3 data/extract_job_definitions.py \
    /tmp/relion_src/src/pipeline_jobs.cpp \
    /tmp/relion_src/src/pipeline_jobs.h \
    /tmp/relion_src/src/gui_jobwindow.cpp \
    data/job_definitions_raw.json
```
